| No | Register offset | Register name | Function               |
|----|-----------------|---------------|------------------------|
| 1  | 0x00            | CMD           | Command                |
| 2  | 0x04            | DATA_TX       | Data to write FIFO     |
| 3  | 0x08            | DATA_RX       | Data to read FIFO      |
| 4  | 0x0C            | ADDR_COL      | Column address         |
| 5  | 0x10            | ADDR_ROW      | Row address            |
| 6  | 0x14            | STATUS        | Status flag            |
| 7  | 0x18            | CONFIG        | Config                 |
| 8  | 0x1C            | INT_EN        | Interrupt              |
